# HR Attrition Dashboard Using Excel 📊

## 📌 Project Overview
This project focuses on analyzing employee attrition using Microsoft Excel. The dashboard provides insights into employee turnover, demographics, job satisfaction, and departmental performance to help understand workforce trends and support data-driven HR decisions.

## 🎯 Project Objectives
- Analyze employee attrition across different departments and job roles.
- Understand workforce distribution by age, gender, education, and marital status.
- Examine job satisfaction and employee-related factors.
- Present HR data through an interactive and easy-to-understand dashboard.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables and Pivot Charts
- Data Cleaning and Data Analysis
- Dashboard Design and Data Visualization
- Excel Filters and Slicers

## 📊 Key Features
- Employee attrition analysis by department and job role.
- Gender-wise and age-wise workforce analysis.
- Education and marital-status-based analysis.
- Job satisfaction ratings and employee demographics.
- Interactive visualizations for exploring HR data.

## 💡 Key Insights
- Identify departments and job roles with higher employee attrition.
- Explore workforce patterns across demographic categories.
- Understand how job satisfaction and employment factors can relate to employee turnover.
- Support HR teams in identifying areas that may need further investigation.

## 🚀 Project Outcome
This project demonstrates practical Excel skills in data analysis, reporting, and dashboard creation. It showcases how raw HR data can be transformed into meaningful visual insights to support workforce planning and employee retention strategies.
